# Slots RNG Browser Game

## How to Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - index.html
   - style.css
   - script.js
3. Go to:
   Settings -> Pages
4. Under "Source", choose:
   Deploy from branch
5. Select:
   main branch / root
6. Save.
7. Wait around 1 minute.
8. Your game will be live.
